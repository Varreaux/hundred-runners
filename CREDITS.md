## Music

Four tracks, loaded in `MUSIC.SRC` and played by act:

| File | Where it plays |
|---|---|
| `Hundred Tutorial Loop.wav` | the tutorial |
| `Hundred Intro New.wav` | the opening, once |
| `Hundred Loop New.wav` | the main bed, looped |
| `Hundred Boss Mastered.wav` | the last room, in the boss phase |

Origin not yet recorded — Morgan to fill in. If these are your own compositions, say so here;
if they came from somewhere, note the source and its licence terms the same way as above.

## Everything else

All code, art and writing in `index.html` is original to this project. No external libraries,
no build step, no third-party assets beyond the audio listed above.

## Adding to this file

One entry per asset, with the **file name as it sits in the repo**, what it is used for, where
it came from, and the licence. The file name matters most: it is the only thing that connects
a line here back to a real file, and it is what makes this list checkable a year from now.
